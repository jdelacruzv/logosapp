# Reglas del proyecto

- Usa 2 espacios para la indentación.
- No utilices tabulaciones.
- Mantén funciones pequeñas y con una única responsabilidad.
- Usa componentes Astro reutilizables.
- Evita duplicar código.
- Escribe comentarios solo cuando aporten contexto útil.
- Respeta Prettier y ESLint.
- No cambies nombres de archivos ni APIs sin justificarlo.
- Mantén compatibilidad con Astro y JavaScript moderno.
